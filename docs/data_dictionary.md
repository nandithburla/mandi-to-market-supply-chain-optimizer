# Data Dictionary

All datasets are **synthetic**, generated by `scripts_generate_raw_data.py` to
imitate real-world agricultural data-quality problems. No government, Mandi,
farmer or sensor data was used.

## 1. Mandi Master (`mandis` / `track3_mandi_master.csv`)

| Column | Description | Type | Unit | Allowed / Expected Values | Transformation |
|---|---|---|---|---|---|
| mandi_id | Unique Mandi identifier | string | - | `MANDI001`-`MANDI057` (canonical) | Normalized via `normalize_mandi_id()` from formats like `MANDI-001`, `mandi_001`, `M001`, `056` |
| mandi_name | Display name of the Mandi | string | - | free text | trimmed |
| district | District the Mandi is located in | string | - | free text, `Unknown District` if missing | missing values filled |
| state | State the Mandi is located in | string | - | Punjab, Haryana, Uttar Pradesh | - |
| mandi_type | Ownership type | string | - | Private, APMC, Direct, Unknown | case-normalized to Title Case |
| total_area_acres | Physical area of the Mandi | float | acres | > 0 or missing | - |

## 2. Arrivals (`arrivals_clean` / `arrivals_features` / `track3_mandi_arrivals.csv`)

| Column | Description | Type | Unit | Allowed / Expected Values | Transformation |
|---|---|---|---|---|---|
| arrival_id | Unique arrival record id | string | - | `ARR#######` or `ARR_GEN_#` (regenerated when missing) | - |
| mandi_id | FK to mandis.mandi_id | string | - | see above | normalized |
| crop_name / crop | Raw / canonical crop name | string | - | Wheat, Rice, Maize, Mustard, Cotton, Sugarcane, Basmati | `normalize_crop()` maps English/Hindi/case variants |
| variety | Crop variety | string | - | Hybrid, Local, Premium, HD-2967, PBW-343, Pusa-1121, Unknown | missing filled with "Unknown" |
| arrival_date | Date of arrival | datetime | - | valid calendar date | parsed via `parse_date_any()` from 10+ raw formats |
| arrival_quantity | Raw reported quantity | float | as given in `unit` | > 0 | negative signs corrected via `abs()` |
| unit | Raw unit of `arrival_quantity` | string | - | KG, Qtl, Tonnes, MT, Q, etc. | - |
| quantity_quintal | Canonical quantity | float | **Quintal** | > 0 | `convert_to_quintal()` |
| farmer_count | Number of farmers contributing | int | - | 5-140 or missing | - |
| quantity_is_missing | Flag: quantity was missing pre-cleaning | bool | - | True/False | derived |

## 3. Prices & MSP (`prices_clean` / `price_features`, `msp` / `track3_price_and_msp.json`)

| Column | Description | Type | Unit | Allowed / Expected Values | Transformation |
|---|---|---|---|---|---|
| price_id | Unique price record id | string | - | `PRC#######` | - |
| mandi_id | FK to mandis.mandi_id (nullable) | string | - | - | normalized |
| district | District (used when mandi_id missing) | string | - | - | - |
| crop_name / crop | Raw / canonical crop | string | - | see Arrivals | `normalize_crop()` |
| price_date | Date of the price quote | datetime | - | valid date | `parse_date_any()` |
| min_price / max_price / modal_price | Wholesale price | float | **INR / Quintal** | > 0 | `clean_price_string()` strips ₹ / Rs. / INR / commas |
| currency | Reported currency | string | - | INR (default when missing) | - |
| msp_per_quintal | Minimum Support Price | float | INR / Quintal | ~1900-2700 | - |
| msp_gap | Modal Price - MSP | float | INR / Quintal | any | derived |
| msp_gap_pct | (msp_gap / MSP) x 100 | float | % | any | derived |
| below_msp | msp_gap < 0 | bool | - | True/False | derived |

## 4. Weather (`weather_clean` / `weather_daily`, `track3_weather_sensors.xlsx`)

| Column | Description | Type | Unit | Allowed / Expected Values | Transformation |
|---|---|---|---|---|---|
| sensor_id | IoT sensor identifier | string | - | `SEN###` or `UNKNOWN` | - |
| timestamp / timestamp_ist | Raw / canonical reading time | string / datetime | - | tz-aware, **Asia/Kolkata** | `normalize_timezone()` |
| temperature / temperature_c | Raw / canonical temperature | float | **Celsius** | -10 to 55 | `convert_temperature_to_celsius()` |
| rainfall / rainfall_mm | Raw / canonical rainfall | float | **millimetres** | >= 0 (negative sensor glitches clipped) | `convert_rainfall_to_mm()` |
| humidity_percent | Relative humidity | float | % | 0-100 | - |

`weather_daily` aggregates the above to one row per calendar date:
`avg_temperature_c`, `total_rainfall_mm`, `avg_humidity_pct`, `sensor_reading_count`.

## 5. Transport / Logistics (`transport_clean`, `track3_transport_logistics.csv`)

| Column | Description | Type | Unit | Allowed / Expected Values | Transformation |
|---|---|---|---|---|---|
| trip_id | Unique trip id | string | - | `TRP######` | - |
| mandi_id | FK to mandis.mandi_id | string | - | - | normalized |
| destination_warehouse | Destination | string | - | WH-Central/North/South/East/West, Export-Terminal | - |
| departure_time / arrival_time | Raw timestamps | string | - | mixed formats | `parse_date_any()` |
| transit_hours / transit_hours_clean | Raw / recomputed transit duration | float | hours | >= 0 | recomputed from arrival - departure when possible |
| distance / distance_km | Raw / canonical distance | float | **km** | > 0 | `convert_distance_to_km()` (miles -> km) |
| vehicle_no / vehicle_no_clean | Vehicle registration | string | - | canonical = upper-case, no spaces/dashes | - |
| driver_id | Driver identifier | string | - | `DRV###` | - |

## 6. Derived analytical table: `market_value`

| Column | Description |
|---|---|
| estimated_market_value | `quantity_quintal x modal_price` for the same (mandi, crop, date); NaN where no matching price exists |
